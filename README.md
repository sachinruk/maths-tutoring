# HSC Maths Tutoring

Static site for Sachin Abeywardana's HSC maths tutoring (Mathematics Advanced, Extension 1, Extension 2).

Plain HTML and CSS, no build step. Hosted on GitHub Pages from the `main` branch.

- `index.html`: the home page
- `maths-advanced-tutor/`, `extension-1-maths-tutor/`, `extension-2-maths-tutor/`: course pages, generated by `python3 tools/build_course_pages.py` (edit the course data there, not the HTML)
- `site.js`: shared page behaviour and analytics events
- `styles.css`: styles
- `practice/`: paper selection and full solutions for 2025 Advanced, 2026 Advanced, 2025 Extension 1 and 2026 Extension 2, with topic filters and solution timers
- `content/*.json`: independently written solutions, tags, marks and official PDF page references; edit these rather than the generated practice HTML
- `assets/practice/`: practice interactions, styles and generated solution sketches
- `assets/vendor/katex/`: pinned KaTeX 0.16.11 (MIT licence included), used to compile accessible maths and serve fonts locally
- `assets/`: photo and favicon

The contact form posts to [FormSubmit](https://formsubmit.co). The first submission sends a confirmation email that must be clicked once to activate it.

Rebuild course pages and sitemap with `python3 tools/build_course_pages.py`.
Rebuild all practice pages and sketches with `python3 tools/build_practice_page.py --all` and the selection page with `python3 tools/build_practice_index.py` (Python 3.11+ and Node required only for authoring; the deployed site is static).
Math is pre-rendered to HTML and MathML, so explanations and expandable answers work without JavaScript. JavaScript enables filters and timers; times remain in page memory and reset on reload.
Only one question timer runs at a time. Opening or resuming another pauses the previous timer while leaving its solution open. Total study time accumulates active time across questions and is preserved when an individual timer is reset.

Content is derived independently from the official NESA exam. The NESA paper and marking guidelines are linked, not hosted. Third-party tutoring solutions were not used. Generated charts illustrate our solutions and do not reproduce exam diagrams.

The 2025 Extension 1 paper is the requested fallback because the official 2026 paper was not available on 24 October 2026. The 2026 Advanced and Extension 2 marking guidelines were pending at publication; solutions were independently derived and reviewed. For 2025 Extension 1, NESA marking guidelines provided an additional answer check. To add a paper, configure its metadata in `tools/build_practice_page.py`, add its content JSON, include it in `tools/build_practice_index.py`, rebuild pages and the sitemap, and run `node --test tests/practice.test.cjs`.
