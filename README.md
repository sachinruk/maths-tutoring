# HSC Maths Tutoring

Static site for Sachin Abeywardana's HSC maths tutoring (Mathematics Advanced, Extension 1, Extension 2).

Plain HTML and CSS, no build step. Hosted on GitHub Pages from the `main` branch.

- `index.html`: the home page
- `maths-advanced-tutor/`, `extension-1-maths-tutor/`, `extension-2-maths-tutor/`: course pages, generated by `python3 tools/build_course_pages.py` (edit the course data there, not the HTML)
- `site.js`: shared page behaviour and analytics events
- `styles.css`: styles
- `assets/`: photo and favicon

The contact form posts to [FormSubmit](https://formsubmit.co). The first submission sends a confirmation email that must be clicked once to activate it.
